About the webiste:

  - after registration login page is redirected and then that user's profile according to their role's profile will open
    
  - role -> AUTHOR
      - can write articles
      - view
      - edit
      - delete
  - role -> USER
      - view articles
      - comment on articles
  - role -> ADMIN
      - view articles
      - block articles
